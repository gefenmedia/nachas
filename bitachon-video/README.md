# Bulletproof Bitachon — narration → animated video

Faceless kinetic typography + simple 2D motion graphics, locked to the narration.
Free stack only: Remotion (Free License: individuals / up to 3 people), local
speech-to-text, FFmpeg, OFL Google Fonts bundled in `public/fonts`, procedural SVG.

## Layout

| Path | What |
|---|---|
| `src/data/plan.json` | **Per episode, hand-written.** Title, hook, CTA, music, and the scene plan (anchor phrase → visual, trigger word, stamps, pulses). |
| `src/data/captions.raw.json` | Raw word timings from transcription |
| `src/data/captions.json` | Proofread word timings (Remotion `Caption[]`) |
| `src/data/chunks.json`, `scenes.json`, `episode.json` | Generated by `scripts/build-scenes.mjs` |
| `transcript.txt`, `scene-list.md` | Readable transcript and shot list |
| `src/visuals/library.tsx` | 30+ reusable modest visuals (siddur, path, door, flame, sunrise, minyan, …) |
| `src/components/` | Captions (2–4 words, gold active word, 85→110→100% bounce), background, stamps |
| `src/lib/ducking.ts` | Music ducking (≈18 dB under voice while speaking, ≈8 dB in pauses) |
| `src/theme.ts` | Palette, fonts, safe-area layouts for 9:16 and 16:9 |

Compositions: `BulletproofBitachonVertical` (1080×1920) and `BulletproofBitachonHorizontal` (1920×1080), 30 fps.
Props: `narrationSrc`, `musicSrc` (MUSIC_PATH), `musicVolume`, `title`, `episode`, `chunks`, `scenes`.

## One-time setup

```bash
npm install
pip install sherpa-onnx soundfile numpy
# Speech model (free, local): NVIDIA Parakeet TDT 0.6b v2 via sherpa-onnx GitHub releases
mkdir -p models && cd models
curl -LO https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v2-int8.tar.bz2
tar xjf sherpa-onnx-nemo-parakeet-tdt-0.6b-v2-int8.tar.bz2 && cd ..
```

> The brand standard is Whisper.cpp 1.5.5 + `medium.en` (`@remotion/install-whisper-cpp`).
> It needs huggingface.co for the model. Where that host is reachable you can use it
> instead; write its `toCaptions()` output to `src/data/captions.raw.json` and continue
> from step 3. Everything after transcription is identical.

## Every new episode

```bash
# 1. Drop the narration in
cp /path/to/episode.mp3 public/narration.mp3

# 2. Transcribe locally (≈20 s for 5 min of audio on 4 CPU cores)
ffmpeg -y -i public/narration.mp3 -ar 16000 -ac 1 -c:a pcm_s16le scripts/narration16k.wav
python3 scripts/transcribe.py scripts/narration16k.wav models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v2-int8 src/data/captions.raw.json

# 3. Proofread (glossary in scripts/proofread.mjs — add new terms there)
#    HASHEM_PRONOUNS_FROM_MS capitalises He/Him/His after that time (per episode; set to a huge number to disable)
HASHEM_PRONOUNS_FROM_MS=999999999 node scripts/proofread.mjs
#    → check transcript.txt

# 4. Write src/data/plan.json (anchors are phrases copied from transcript.txt), then
node scripts/build-scenes.mjs public/narration.mp3
#    → check scene-list.md; fix any WARN lines

# 5. 10-second preview ONLY, then stop for approval
npx remotion render BulletproofBitachonVertical out/preview-10s.mp4 --frames=0-299

# 6. After approval
npx remotion render BulletproofBitachonVertical out/bulletproof-bitachon-<slug>.mp4
npx remotion render BulletproofBitachonHorizontal out/bulletproof-bitachon-<slug>-16x9.mp4
```

Preview interactively: `npx remotion studio`.

Restricted network / no Chrome download: set
`REMOTION_BROWSER=/path/to/chrome-headless-shell` (read by `remotion.config.ts`).

## Music

`episode.music.src` in `plan.json` points at a file in `public/`. The default is an original
placeholder pad generated by `bash scripts/make-placeholder-pad.sh` (no third-party rights).
To use a real track: download an **instrumental** track from the YouTube Audio Library
(filter "Attribution not required"), save it as `public/music/<name>.mp3`, update
`music.src/title/source/license/attribution` in `plan.json`, re-run `build-scenes.mjs`.
No vocals (kol isha), no Content-ID-flagged Pixabay tracks.

## Brand rules (short)

No people/faces, no depiction of Hashem or angels, no sheimos on screen ("Hashem",
"G-d", "HaKadosh Baruch Hu" are fine), instrumental music only, hook text on frame 0,
captions in the middle third (48–66% down), end card 2 s after the last word.
